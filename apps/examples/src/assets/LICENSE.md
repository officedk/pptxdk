本目录中的销售数据为 react-pptx 示例专门编写的合成数据，不来自外部数据源，也不代表真实企业或客户。

该数据可随仓库复制、修改和用于示例与自动验收，无需另行获取第三方许可。

`fonts/` 中的 Montserrat 与 Jost 字体文件随各自的 SIL Open Font License 1.1 文本提供。Montserrat 归 Montserrat.Git Project Authors，来源项目为 https://github.com/JulietaUla/Montserrat.git；Jost 归 Jost Project Authors，来源项目为 https://github.com/indestructible-type/Jost。字体文件可依随附许可证用于度量、嵌入及再分发。

能力册使用的 ZCOOL XiaoWei 静态 TrueType 字体来自公开 `@expo-google-fonts/zcool-xiaowei@0.4.1` 包中的 `ZCOOLXiaoWei_400Regular.ttf`，字族作者为 ZCOOL，随附 SIL Open Font License 1.1。包元数据、候选来源记录和原许可证一并保存在 `fonts/`。能力册封面图片 `capability-observatory.png` 为本示例专门生成的原创插画，不包含第三方图像素材。

School 原稿中的标题字体为 Tw Cen MT；本示例不分发该字体，以 Jost 字体文件明确提供度量替代，并保留 PPTX 中原稿字体族名称。所选 services 与 agenda 页面不使用位图图片，图标和装饰均由可编辑形状组成。
